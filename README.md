# Что приготовить?

**Приложение:** https://vysockiymark01-prog.github.io/chto-prigotovit/

PWA-приложение для подбора рецептов по бюджету. Вводите сумму — получаете варианты блюд, которые можно приготовить на эти деньги. Работает офлайн, все данные и настройки хранятся локально в браузере.

## Возможности

- Подбор рецептов по бюджету, типу приёма пищи, времени готовки
- Два режима расчёта: стоимость одной порции и стоимость закупки всех продуктов с нуля
- 🎲 «Придумать блюдо» — случайный рецепт в рамках бюджета и фильтров; если под бюджет ничего не подходит, берёт ближайший по цене, а не первый попавшийся
- Поиск по продуктам, которые есть под рукой — добавляете продукты (например, «курица», «картошка», можно сразу несколько через запятую), и список показывает рецепты с ними, сначала с наибольшим совпадением; поиск нечёткий — не нужно вводить точное название из базы
- Свои продукты — если продукта нет в базе, его можно добавить самостоятельно (название, цена, единица измерения); своими продуктами можно поделиться текстом (кнопка «Поделиться» на экране «Продукты и цены») и импортировать чужой список
- Свои цены на продукты вместо средних — пересчёт мгновенно на всех экранах
- «Есть дома» — отметьте, что уже есть на кухне, и стоимость закупки пересчитается
- Избранное и список покупок с автоматическим суммированием одинаковых продуктов из разных рецептов
- Светлая / тёмная / системная тема
- Полностью работает офлайн после первого захода (PWA, service worker); при выходе новой версии открытая вкладка сама обновляется и подхватывает актуальный код

## Стек

React 18 + Vite (JavaScript), react-router, vite-plugin-pwa. Без бэкенда — все данные статичные (`src/data`), пользовательские — в `localStorage`.

## Разработка

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # прод-сборка в dist/
npm run deploy   # сборка + публикация в ветку gh-pages
```

## Структура

- `src/data/` — база продуктов и рецептов (JSON)
- `src/lib/pricing.js` — расчёт стоимости порции/закупки, пользовательские цены
- `src/context/` — состояние приложения (цены, «есть дома», избранное, список покупок, тема)
- `src/pages/` — экраны (Подбор, Рецепт, Избранное, Список покупок, Есть дома, Продукты и цены)
